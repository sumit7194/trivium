# Blind object — leg 3

A 4-dimensional Lorentzian metric. **No claim is attached to it.** You are not being told
whether it is integrable, whether anything has been found on it, or where it came from.

Coordinates `(t, xi, eta, s)`, all real. Signature is for you to determine.

    rho^2 = xi^2 + eta^2
    U     = 2 a xi / rho^2                       a > 0 real

    g_tt = -2U        g_ts = g_st = 1
    g_xixi = g_etaeta = 8 rho^2
    all other components zero

Hamiltonian convention `H = (1/2) g^{ab} p_a p_b`, bracket
`{A,B} = sum_a (dA/dx^a dB/dp_a - dA/dp_a dB/dx^a)`.

## What is asked

Whatever your own instrument returns on an object of this kind, run it and report the number
before being told anything. Do not ask what the expected answer is; the point of the exercise is
destroyed by knowing it.

There IS a definite exact answer. It is held by the bridge and will be published to every
participant at the same time, after all verdicts are in.
